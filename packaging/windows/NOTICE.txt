This build contains only the open-source Community edition. It has no cloud
or sync services and sends no data anywhere: your notes stay as plain
Markdown files in the folder you choose.

Running it
----------
Portable zip: extract the folder anywhere and run neural-thinker.exe.
Installer:    installs for the current user only (no administrator rights)
              and adds a Start menu entry; uninstall from Windows Settings.

The executable is not code-signed, so Windows SmartScreen may warn the first
time. Choose "More info" and then "Run anyway" if you trust this download.
Each release lists SHA-256 checksums so you can verify the files.
